# AI Company Personnel Research

This is a non-commercial academic research project studying executives,
researchers, engineers, and other key personnel associated with AI
infrastructure companies.

The project may use the ORCID Public API to retrieve information that
researchers have made publicly available, including:

- employment history
- education
- research affiliations
- public researcher identifiers

The project does not modify ORCID records and does not access private or
trusted-party information.
